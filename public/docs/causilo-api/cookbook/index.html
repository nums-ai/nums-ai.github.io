Cookbooks

Short scripts you can run as they are, each with the output it produced against the live API. They read CAUSILO_ENDPOINT and CAUSILO_KEY from the environment.

  2. Causilo vs XGBoostThe same call next to XGBoost and LightGBM at their defaults, on one dataset.
  3. Usage, limits and cancellationRead the limits before sending, handle the two 429s, and see a timeout refund its charge.
