Getting started

Predict missing values in tables.

Send rows with known answers as context and rows without answers as query. Causilo returns one prediction for each query row—without a separate model-training step.

RuntimePython 3.11+
TasksClassification · Regression
TransportHTTPS · Parquet
i
Authentication is assigned separately.

Use the service-account key or operator-issued token provided for your integration.

i
A temporary usage allowance applies.

The current allowance is 2 billion cells per month and may change. Contact the operator before planned large-scale use.

02

Five-minute quickstart

Install the client, configure authentication, and make a first prediction.

1

Install the client

Install it from PyPI into your Python 3.11+ environment.

ShellInstall
python -m pip install -U causilo-client
python -c "from causilo_client import Causilo; print('causilo_client import OK')"

Required packages—pandas, pyarrow, requests, and google-auth—are installed automatically. The client also handles authentication headers, DataFrame-to-Parquet serialization, and retryable connection failures.

2

Configure authentication

The operator will assign one method. Use only the method provided to you.

MethodWhen usedClient argument
Service-account keyDefault when Google authentication is reachableCausilo(endpoint, key_file=...)
Operator-issued tokenWhen token access has been enabledCausilo(endpoint, token=...)
ShellKey-file security
export CAUSILO_ENDPOINT=https://<the URL you were given>
export CAUSILO_KEY_FILE=/secure/path/causilo-key.json
chmod 600 "$CAUSILO_KEY_FILE"
i
The key needs two hosts reachable.

With a service-account key the client mints a Google ID token before every call, so the machine has to reach oauth2.googleapis.com on 443 as well as the endpoint itself. If only the endpoint is open, authentication fails before any request is sent and the client reports which of the two to check. Ask for an operator-issued token instead when the outbound rule cannot be widened.

3

Run a classification prediction

The context includes the target column; the query excludes it. Both tables must use the same feature names and order.

PythonClassification
import os

import pandas as pd
from causilo_client import Causilo

rx = Causilo(
    os.environ["CAUSILO_ENDPOINT"],
    key_file=os.environ["CAUSILO_KEY_FILE"],
)

# Optional: start the service while tables are prepared.
rx.wake()

context = pd.read_parquet("train.parquet")   # target included
query = pd.read_parquet("predict.parquet")   # target excluded

pred = rx.predict(
    context=context,
    query=query,
    target="churned",
    model="causilo-clf",
)

# Alternative: return predictions together with metadata.
pred, meta = rx.predict_with_metadata(
    context=context,
    query=query,
    target="churned",
    model="causilo-clf",
)
✓
Default classification output

A probability matrix with one row per query. Use metadata["classes"] to map columns to labels.

4

Run a regression prediction

Use the regression model key and choose a point estimate or requested quantiles.

PythonRegression
# One mean prediction per query row
pred = rx.predict(
    context,
    query,
    target="amount",
    model="causilo-reg",
)

# Prediction intervals at requested quantile levels
pred, meta = rx.predict_with_metadata(
    context,
    query,
    target="amount",
    model="causilo-reg",
    output_type="quantiles",
    quantiles=[0.1, 0.5, 0.9],
)
Integration checklist5 steps
  1. Confirm connectivity. Call rx.wake() and expect True.
  2. Run a small sample. Start with approximately 100 real rows.
  3. Inspect data types. Check for datetime columns and numeric strings.
  4. Run the full dataset. Reduce a request if 413 reports a size limit.
  5. Verify metadata. Confirm class or quantile column order.

03

Core data contract

The server validates table structure before running inference.

InputShapeRequirements
contextRows × features plus targetAt least one row; target present with no missing values
queryRows × featuresAt least one row; target column absent
Feature columnsAt least one columnNames, order, and data types match between tables

Classification supports up to 64 target classes.

Request-size budget

Cells per request(context rows + query rows) × feature columns
HTTP body limit32 MiB

Enforced by the platform, before the request reaches the model. This is the limit you meet first.

Cells that fitDepends on the data

Compression decides it. Measured with zstd Parquet: 3.5M cells of random float64, 6.0M of float32, 25M of two-decimal floats, 37M of small integers.

ChunkingAutomatic

Large tables are processed in parts; output is unchanged and metadata adds a warning.

Time grows faster than the table does. Most of it tracks the number of context rows rather than the cell count, and that term is quadratic — 10,000 rows at 10 features measured 160 µs per row, and 40,000 rows at the same width measured 250 µs per row. Two requests with the same number of cells can differ by a quarter: 10,000 × 50 measured 4.0 s against 4.9 s for 20,000 × 20.

!
A 413 response identifies the relevant limit.

The error message distinguishes cell count from byte count and reports the measured request size. Split using the numeric limit in that message.

Outputs and metadata

Choose a task-specific output and use metadata to interpret its columns.

TaskOutput typeDefaultPython typeShape
ClassificationprobasYeslist[list[float]]n × classes
ClassificationpredsNolist[int] | list[str]n
RegressionmeanYeslist[float]n
RegressionmedianNolist[float]n

Predictions are ordinary Python lists, not NumPy arrays. Convert before multidimensional indexing.

PythonList → array
import numpy as np

arr = np.asarray(pred)
first_column = arr[:, 0]
  • A single requested quantile still returns an n × 1 nested list.
  • Non-finite computed predictions are returned as None; in JSON, they are null.
  • Task-incompatible output types return 422.

i
Metadata names the weights that answered.

The model field repeats the key that was requested, and a key is served by whichever checkpoint the running service holds, so two responses carrying the same key are not on their own evidence that the same weights answered. The evidence is served_by.checkpoint: a digest of the weights file, equal across instances when the weights are byte-identical. Record it alongside any result you may have to account for later.

Map quantile columns safely

Quantile columns preserve the requested order rather than sorting it. Classification classes are sorted and may not follow first appearance.

PythonMetadata mapping
import numpy as np

pred, meta = rx.predict_with_metadata(
    context,
    query,
    target="amount",
    model="causilo-reg",
    output_type="quantiles",
    quantiles=[0.1, 0.5, 0.9],
)

levels = meta["quantiles"]
arr = np.asarray(pred)
lower = arr[:, levels.index(0.1)]

Data validation

Convert ambiguous or unsafe values before sending them.

Inputs rejected with 422

Rejected inputRequired conversion
Datetime or timedelta featuresSplit into year, month, day, weekday, or other numeric features
Decimal featuresConvert to float
Query feature entirely missingRemove the column or populate values
Infinite feature valuesReplace with finite values or missing values
Fractional classification labelsUse integer or string labels
Lists or dictionaries in cellsExpand into scalar columns
Feature |value| ≥ 9.5e+150Rescale or replace with missing data
Context/query type mismatchUse identical types; numeric and boolean also differ
Regression target stored as stringsConvert to numeric or use classification
Datetime regression targetConvert to numeric values in an explicit unit
Infinite regression targetReplace or remove the row
Regression target |value| ≥ 3.4e+38Change units or apply a log transform
Classification target stored as bytesDecode to strings or use numeric labels
Duplicate column namesRename columns to be unique
quantiles with another output typeRemove quantiles or select quantile output
✓
float16 tables are accepted.

The server converts them to float32; no client-side conversion is required.

Accepted inputs that reduce accuracy

Numeric strings

Values lose numeric ordering.

Convert strings such as “1”, “2”, and “3” with pd.to_numeric(...). Keep genuine identifiers such as postal or product codes as strings.

Extreme sentinels

Whole rows can distort the table.

Replace values such as -9999999 with NaN. The issue is the gap from surrounding values, not large units by themselves.

Non-predictive IDs

Identifiers become unintended features.

Remove customer IDs and row numbers unless they are intentionally part of the model signal.

Measured conditionObserved accuracy change
One extreme cell1.000 → 1.000; another table: 0.963 → 0.944
Every feature in one row is extreme1.000 → 0.614; another table: 0.963 → 0.352

A column mixing numbers and strings usually fails during Parquet conversion. Normalize it to one data type before transmission.

The service scales to zero when idle. Use wake() while preparing data and select timeouts based on end-to-end latency.

09

Errors and troubleshooting

Exceptions carry a status and a direct next action.

ExceptionStatusAction
RadixValidationError422Correct the column or type named in the message
RadixTooLarge413Reduce rows or columns using the reported limit. Two things produce this — the table does not fit in memory, or it is predicted to run longer than this deployment allows. Either way the message names a size that would work
RadixAuthError403The credential is valid but not permitted here: grant the service account the invoker role
RadixAuthError401The credential was not accepted: check the key file or token
RadixUnavailable503Wait briefly; automatic retries already ran. A busy GPU also answers here
RadixTimeout—No reply within timeout=. Not retried, because the server is still computing and a retry is charged again. The client tells the server it gave up, and the charge for that call is released; the message says whether it was
RadixQuotaExceeded429Monthly cell quota is spent; it resets on the 1st, 09:00 KST. Read .scope first — "caller" means this key alone, so another key still works; "tenant" means the whole account, and no key will
RadixOverloaded429No instance came free in time; retry shortly, nothing was charged
RadixError500Provide reproduction conditions; the operator is alerted
!
A 413 can be about time rather than size.

Besides the byte and cell limits, a table predicted to hold the GPU longer than the 300 seconds this deployment allows for one request is refused with 413 request_too_large before anything is charged. The message names how many context rows fit at that column count. Cut context rows rather than query rows, because the context table is where the time goes.

i
Send the complete exception message when requesting support.

Include the smallest dataset shape that reproduces the failure. Messages usually identify the offending column, type, or size directly.

Every message ends with a request identifier, also available as error.request_id and in the X-Request-Id response header. It is what lets us find your call in our logs. Without it the only way to match a report to a request is by timestamp, and the failure records deliberately carry no column names or data values to narrow it down.

i
Results are reproducible to within one bit, not bit for bit.

Repeated calls usually return byte-identical numbers, and two calls served by different instances of the service can differ in the last bit of a float — one or two units in the last place, around 5e-07 on values near 5. No prediction changes: class labels are identical and regression figures agree far beyond any significant digit you would report. If you compare two stored results and find a difference at that scale, the model did not change. Check metadata.served_by.checkpoint; identical digests mean identical weights.

i
Time grows faster than the table does.

Cost tracks the number of context rows rather than the cell count, and that term is quadratic. Two requests of the same size can differ by a quarter. If a table is refused for being too slow, cutting context rows helps far more than cutting query rows — and splitting the query across calls does not help at all, because each call resends the context table and pays for it again.

10

REST API and support

Use the Python client by default; use the HTTP contract for other languages.

POST/invocations

Multipart request containing two Parquet files and JSON parameters. An OpenAPI 3.1 specification is supplied separately.

POST/cancel

Releases the charge for a request you have stopped waiting on. Send an X-Radix-Cancel-Key header with every /invocations call, 16 to 128 letters and digits, a new key for every request and every retry, and POST /cancel with the same header when you give up. The reply is cancelled, refunded and request_id; refunded is 0 when the response had already gone out. The Python client does this by itself on its own timeout. On the raw HTTP contract it is your call to make, and without the header there is nothing to cancel. A second request on a key whose first request is still running is refused with 409 cancel_key_in_use and charged nothing.

GET/usage

The month so far for the calling credential: used, remaining, limit and resets_at. metered is false when no cap applies. There is no parameter naming whose usage to return; the credential is the answer.
